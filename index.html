Promises the rules keep.

Each one is a check that runs before money moves. If any check fails, nothing is signed.

01A cap per payment

Your AI can't pay more than the limit you set for a single request, whatever it's told.

02An x402 limit per day

When today's x402 limit is used up, payments stop until tomorrow.

03Only payees you approve

A new address is refused until you add it yourself.

04A contract, not a promise

Every rule lives in your own Allot Vault on Robinhood Chain. A leaked AI key still can't spend more.

05Revoke in one click

Pull the allowance back to your wallet and the AI can't pay again.

06No unlimited approvals

Each payment is a one-time signed authorization for its exact amount.

One connector, a few lines.

A small MCP server that runs on your own machine. It gives your AI one tool to pay an x402 request and one to check what it can still spend. The rules live in the connector and in the allowance wallet, not in the AI.

{
  "mcpServers": {
    "allot": {
      "command": "npx",
      "args": ["-y", "github:byte402/allot-connector"],
      "env": {
        "ALLOT_PER_PAYMENT": "0.05",
        "ALLOT_PER_DAY": "1.00"
      }
    }
  }
}
